\chapter{Features and Customization}
\label{ch:features}

This chapter highlights the advanced typographical features and custom environments built into the \mintinline{text}{IISERKphysics.sty} package.

\section{Font Customization}
You can easily switch out the document fonts by using the font macros in \mintinline{text}{main.tex}. These macros take an optional LaTeX package name and a styling command.
\begin{minted}{latex}
% Example: Use 'tgheros' for sans-serif headings, 'tgtermes' for Times main text
\TitleFont[tgheros]{\sffamily}
\TextFont[tgtermes]{\rmfamily}
\MathFont{newtxmath}
\end{minted}
If you leave these commented out, the template elegantly defaults to Garamond.

\section{Theorem Environments}
We provide beautifully styled theorem environments powered by \mintinline{latex}{tcolorbox}. These boxes are fully integrated with \mintinline{latex}{cleveref} for smart cross-referencing.

\begin{theorem}{No-Hair Theorem}{nohair}
    Stationary black holes are characterized entirely by mass $M$, charge $Q$, and angular momentum $J$.
\end{theorem}

\begin{lemma}{}{}
    This is a lemma without a title. Notice how the numbering follows the theorem counter chapter-wise.
\end{lemma}

\begin{definition}{Event Horizon}{horizon}
    The boundary defining the region of space from which nothing can escape.
\end{definition}

\begin{remark}{Historical Note}{hist}
    The term was popularized by John Wheeler in 1967.
\end{remark}

You can reference these dynamically: use \mintinline{latex}{\cref} for lowercase mid-sentence citations (\cref{thm:nohair} and \cref{def:horizon}) and \mintinline{latex}{\Cref} when opening a sentence (\Cref{thm:nohair} characterizes black hole geometries).

\section{Mathematics and Physics}
Essential math packages like \mintinline{latex}{amsmath}, \mintinline{latex}{mathtools}, \mintinline{latex}{slashed}, and \mintinline{latex}{tensor} are preloaded. The \mintinline{latex}{physics} package provides excellent shorthand for bra-ket notation and derivatives:
\begin{equation}
    \hat{H} \ket{\Psi} = i\hbar \pdv{t} \ket{\Psi}
    \label{eq:schrodinger}
\end{equation}
\Cref{eq:schrodinger} is the time-dependent Schrödinger equation, which can also be cited mid-sentence as \cref{eq:schrodinger}.

You can also log symbols to the Nomenclature automatically. For instance, consider the speed of light $c$.
\nomenclature{$c$}{Speed of light in a vacuum}
\nomenclature{$\ket{\Psi}$}{Quantum state vector}

\section{Citations and Bibliography}
\label{sec:citations}
Bibliography management is configured out of the box using \mintinline{latex}{biblatex} with the \mintinline{text}{biber} backend. Citations are stored in \mintinline{text}{references.bib} (registered via \mintinline{latex}{\addbibresource{references.bib}} in \mintinline{text}{main.tex}), and the bibliography is printed at the end of the document with \mintinline{latex}{\printbibliography[heading=bibintoc]}.

The template provides an author-year citation style (\mintinline{latex}{citestyle=authoryear}) paired with a numeric bibliography list (\mintinline{latex}{bibstyle=numeric}). We provide a custom implementation of \mintinline{latex}{\textcite} that links both the author name and the publication year directly to the bibliography entry in dark green (\mintinline{latex}{citecolor}), while keeping parentheses unlinked.

\begin{itemize}
    \item \textbf{Narrative citation}: Use \mintinline{latex}{\textcite{key}} when the author's name forms a natural part of the sentence:
          \begin{quote}
              As formulated by \textcite{einstein1915}, gravitational interactions arise from the curvature of spacetime.
          \end{quote}
    \item \textbf{Parenthetical citation}: Use \mintinline{latex}{\parencite{key}} when referring to literature parenthetically:
          \begin{quote}
              Gravitational radiation from black hole collisions was analyzed in seminal work \parencite{hawking1971}, extending theorems on gravitational collapse \parencite{penrose1965}.
          \end{quote}
    \item \textbf{Multiple citations}: Separate multiple citation keys with commas inside \mintinline{latex}{\parencite{...}}:
          \begin{quote}
              Foundational developments in general relativity and singularity formation are well documented \parencite{hawking1971,penrose1965,einstein1915}.
          \end{quote}
\end{itemize}

Here is how you write these in your source:
\begin{minted}{latex}
% Narrative citation: Einstein (1915)
As formulated by \textcite{einstein1915}, gravitational interactions...

% Parenthetical citation: (Hawking 1971)
Gravitational radiation was analyzed in seminal work \parencite{hawking1971}...

% Multiple references: (Hawking 1971; Penrose 1965)
Foundational developments are well documented \parencite{hawking1971, penrose1965}.
\end{minted}

\subsection{Tables and Subtables}
Avoid vertical lines in scientific tables. The \mintinline{latex}{booktabs} package provides clean horizontal rules: \mintinline{latex}{\toprule}, \mintinline{latex}{\midrule}, and \mintinline{latex}{\bottomrule}. Place the \mintinline{latex}{\caption} \emph{above} the table body, adhering to standard scientific publishing conventions.

\Cref{tab:constants} demonstrates a standard single table. Mid-sentence citations automatically take the lowercase form (for example, as summarized in \cref{tab:constants}). For side-by-side comparison tables, the \mintinline{latex}{subtable} environment groups multiple tables under a common label, as shown in \cref{tab:mechanics}. Individual subtables can be cited mid-sentence as \cref{tab:sub_kinematics} and \cref{tab:sub_dynamics}, or together as \cref{tab:sub_kinematics,tab:sub_dynamics}. At the start of a sentence, use \mintinline{latex}{\Cref} (for instance, ``\Cref{tab:sub_kinematics} presents kinematics'').

\subsection{Context-Based Capitalization Rule}
\label{sec:cref_capitalization}
Scientific publishing standards (such as APS, IEEE, and Chicago Manual of Style) prescribe \emph{context-based capitalization} for cross-references:
\begin{itemize}
    \item \textbf{Sentence-initial references (\mintinline{latex}{\Cref})}: When opening a sentence, use \mintinline{latex}{\Cref{...}}. It automatically capitalizes the output (e.g., \mintinline{latex}{\Cref{tab:constants}} yields ``\Cref{tab:constants}'').
    \item \textbf{Mid-sentence references (\mintinline{latex}{\cref})}: Within running text or parentheses, use \mintinline{latex}{\cref{...}}. It automatically preserves lowercase (e.g., \mintinline{latex}{\cref{tab:constants}} yields ``\cref{tab:constants}'').
\end{itemize}

\Cref{tab:cref_rules} summarizes the context-based output across primary environments.

\begin{table}[htpb]
    \centering
    \caption{Context-based capitalization commands provided by \mintinline{latex}{cleveref}.}
    \label{tab:cref_rules}
    \begin{tabular}{lcc}
        \toprule
        Environment & Sentence Start (\mintinline{latex}{\Cref})                              & Mid-Sentence (\mintinline{latex}{\cref})                                \\
        \midrule
        Figure      & \mintinline{latex}{\Cref{fig:...}} $\rightarrow$ \Cref{fig:single_logo} & \mintinline{latex}{\cref{fig:...}} $\rightarrow$ \cref{fig:single_logo} \\

        Equation    & \mintinline{latex}{\Cref{eq:...}} $\rightarrow$ \Cref{eq:schrodinger}   & \mintinline{latex}{\cref{eq:...}} $\rightarrow$ \cref{eq:schrodinger}   \\
        Theorem     & \mintinline{latex}{\Cref{thm:...}} $\rightarrow$ \Cref{thm:nohair}      & \mintinline{latex}{\cref{thm:...}} $\rightarrow$ \cref{thm:nohair}      \\

    \end{tabular}
\end{table}

\section{Code Listings}
The template utilizes \mintinline{latex}{minted} for professional code blocks as well as inline code. Crucially, we use the \mintinline{latex}{accsupp} package to render line numbers uncopyable, so readers can effortlessly copy your code from the PDF without grabbing the line numbers.

For inline code, use \mintinline{latex}{\mintinline{<language>}{<code>}} or the shorthand \mintinline{latex}{\code{<code>}}. Inline code is configured with automatic line breaking (\mintinline{latex}{breaklines=true, breakbytoken=true}) so that long file paths, commands, or code tokens wrap automatically according to the text width without overflowing into page margins.

\begin{listing}[htpb]
    \begin{minted}{python}
import numpy as np

def calculate_energy(mass):
    """Calculates rest energy E = mc^2"""
    c = 299792458 # m/s
    return mass * c**2
\end{minted}
    \caption{A simple Python script demonstrating the \mintinline{latex}{minted} configuration.}
    \label{lst:python}
\end{listing}

\section{To-Do Notes}
As you draft your thesis, you can leave yourself notes using the \mintinline{latex}{\todo{}} command.
\todo{This is a margin note. It automatically fits the page margin.}
\todo[inline, color=green!40]{This is an inline todo note, useful for longer comments or reminders inside the text body.}
These notes compile into a handy index at the front of the document. When you are ready to finalize your thesis, simply add the \mintinline{latex}{notodo} class option (see \cref{sec:class_options}) to hide all notes and the list simultaneously.
