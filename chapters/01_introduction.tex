\section{Mathematics and Physics}
The \texttt{IISERKphysics.sty} package automatically loads essential mathematical and physical typesetting tools.
For example, you can seamlessly use the \texttt{physics} package for bra-ket notation and derivatives:
\begin{equation}
    \hat{H} \ket{\Psi} = i\hbar \pdv{t} \ket{\Psi}
\end{equation}
You can also easily define custom symbols for your nomenclature. For example, consider the speed of light $c$.
\nomenclature{$c$}{Speed of light in a vacuum}
\nomenclature{$\ket{\Psi}$}{Quantum state vector}

\section{Code Listings}
The template uses \texttt{minted} for professional, syntax-highlighted code blocks. Line numbers are rendered uncopyable so readers can easily copy the code.

\begin{listing}[htpb]

import numpy as np

def calculate_energy(mass):
    """Calculates rest energy E = mc^2"""
    c = 299792458 # m/s
    return mass * c**2

\section{Citations}
The template utilizes \texttt{biblatex} with the Biber backend. It is configured to automatically parse arXiv and DOI links.
You can use standard citations \parencite{hawking1971} or text citations where the author's name becomes the clickable link, such as \textcite{einstein1915}.
